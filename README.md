A collection of all my open-source repositories, used for mirror backups.

You can access it at [Codeberg](https://codeberg.org/lingyicute/repoPackage), [GitHub](https://github.com/lingyicute/repoPackage), [GitLab](https://gitlab.com/lingyicute/repoPackage), [Gitea](https://gitea.com/lingyicute/repoPackage), [Tangled](https://tangled.org/lingyicute.tngl.sh/repoPackage), [CodeFloe](https://codefloe.com/lingyicute/repoPackage), [Disroot](https://git.disroot.org/lingyicute/repoPackage), [pub.solar](https://git.pub.solar/lingyicute/repoPackage), [OpenCommit](https://opencommit.eu/lingyicute/repoPackage), [envs](https://git.envs.net/lingyicute/repoPackage), [tildegit](https://tildegit.org/lingyicute/repoPackage), [bolha](https://bolha.dev/lingyicute/repoPackage), [Framagit](https://framagit.org/lingyicute/repoPackage), [GitGud](https://gitgud.io/lingyicute/repoPackage), [git.gay](https://git.gay/lingyicute/repoPackage), [Gitoro](https://gitoro.com/lingyicute/repoPackage), [SourceForge](https://sourceforge.net/p/lyi-repopackage) and [Bitbucket](https://bitbucket.org/lingyicute/repoPackage).

There is also a test mirror on [Gogs Demo](https://try.gogs.io/lingyicute/repoPackage) and a tarball archive on [HuggingFace](https://huggingface.co/datasets/lingyicute/repoPackage/blob/main/repoPackage.tar.gz).
