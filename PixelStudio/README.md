# 像素工坊 PixelStudio

采用 Material You 设计的零依赖、单文件 H5 图片处理工具。所有处理均在浏览器本地完成，图片不会上传至任何服务器。

## 功能

- **像素级裁剪**：原尺寸裁剪不重新采样；支持手柄拖拽、精确像素输入与键盘微调，内置常用比例预设
- **旋转与翻转**：支持 90° 旋转与水平 / 垂直镜像翻转，选区随画面同步变换
- **尺寸调整**：支持等比或自由缩放、百分比滑块与常用分辨率预设。最近邻保留硬边；平滑效果因浏览器而异，高质量模式在大幅缩小时分级采样
- **EXIF 元数据**：编辑 JPEG / PNG / WebP 的常用相机参数、拍摄时间与 GPS 坐标。也读取 PNG 文本块中的常用字段（解压需要浏览器支持）。清除只作用于导出文件；无法确认写入或清除时不提供下载
- **格式转换与压缩**：支持 JPEG、PNG、BMP，以及浏览器可编码的 WebP / AVIF。PNG 默认无损编码当前画布；JPEG / BMP 使用所选背景色填充透明区域。质量数值不代表体积缩减比例，最高画质也不保证无损
- **实时画质对比**：对比分隔线两侧分别显示源图裁剪区和当前导出结果。体积变化以整个输入文件为基准，也会受裁剪、缩放和格式转换影响
- **个性化界面**：适配桌面与移动端，内置深浅色模式与五款动态主题色

## 使用

访问 [ps.92li.uk](https://ps.92li.uk)，或直接下载并打开 `index.html`。输入能否解码取决于浏览器；未手选格式时，JPEG、可编码的 WebP 或 AVIF 优先导出同格式，其他图像默认导出 PNG 以保留透明度。

输出是从浏览器画布重新编码的静态图片，不保留动画、原图的色彩配置文件或未提供编辑的原始标签。无损仅指对当前画布编码时不进行有损量化，不保证输出与原文件像素存储或二进制字节相同。

EXIF 每项文本最多 32767 个 UTF-8 字节，且 JPEG 的整个 EXIF 段不得超过 64KB。超限或含空字符时不会静默截断，也不会提供下载；请缩短相关文本、改用 PNG / WebP，或选择清除 EXIF。

## 回归测试

- Node.js 22+：`node --test tests/core.test.cjs`，不需要安装依赖。
- 可选浏览器测试：在独立工具目录安装 Playwright 和相应浏览器，将 `NODE_PATH` 指向该目录的 `node_modules`，运行 `node --test tests/browser.test.cjs`。默认运行 Chromium、Firefox 和 WebKit；可用 `BROWSERS=chromium` 单独运行 Chromium。测试直接用浏览器打开本地 `index.html`，不需要启动服务。
