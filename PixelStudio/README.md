# 像素工坊 PixelStudio

采用 Material You 设计的零依赖、单文件 H5 图片处理工具。所有处理均在浏览器本地完成，图片不会上传至任何服务器。

## 功能

- **像素级裁剪**：不缩放时直接提取选区像素；支持手柄拖拽、精确像素输入与键盘方向键微调，内置多种常用比例预设
- **旋转与翻转**：支持 90° 旋转与水平 / 垂直镜像翻转，选区随画面同步变换
- **尺寸调整**：支持等比或自由缩放、百分比滑块、常用分辨率预设及多种重采样算法
- **EXIF 元数据**：支持读写 JPEG / PNG / WebP 的常用相机参数、拍摄时间与 GPS 坐标，可一键清除 EXIF。导出不复制未提供编辑的原始标签
- **格式转换与压缩**：支持 JPEG、PNG、BMP，以及浏览器可编码的 WebP / AVIF。质量数值是编码参数，不是承诺的体积缩减比例；PNG 可无损编码当前画布，BMP 为未压缩 RGB，JPEG / BMP 会填充透明区域
- **实时画质对比**：支持原图与输出结果的拖拽分割线对比，实时预估输出体积变化
- **个性化界面**：适配桌面与移动端，内置深浅色模式与五款动态主题色

## 使用

访问 [ps.92li.uk](https://ps.92li.uk)，或直接下载并打开 `index.html`。输出是重新编码的静态图片，不保留动画或原文件的色彩配置文件。

## 回归测试

- Node.js 22+：`node --test tests/core.test.cjs`，不需要安装依赖。
- 可选浏览器测试：在独立工具目录安装 Playwright 和相应浏览器，将 `NODE_PATH` 指向该目录的 `node_modules`，运行 `node --test tests/browser.test.cjs`。默认运行 Chromium、Firefox 和 WebKit；可用 `BROWSERS=chromium` 单独运行 Chromium。测试直接用浏览器打开本地 `index.html`，不需要启动服务。
